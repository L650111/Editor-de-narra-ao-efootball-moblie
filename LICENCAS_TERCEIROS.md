# Componentes de terceiros

A licença MIT em `LICENSE` se refere ao código próprio deste editor. Os componentes abaixo conservam seus autores e termos originais. Os avisos disponíveis acompanham o pacote em `licencas/` e nos metadados das dependências.

| Componente | Versão usada | Projeto e código-fonte |
|---|---|---|
| CriCodecs | 1.2.0 | https://github.com/Youjose/CriCodecs |
| imageio-ffmpeg | 0.6.0, wrapper BSD-2-Clause | https://github.com/imageio/imageio-ffmpeg |
| FFmpeg portátil Linux | 7.0.2 static, compilação com GPLv3 | https://johnvansickle.com/ffmpeg/ e https://ffmpeg.org/releases/ffmpeg-7.0.2.tar.xz |
| FFmpeg portátil Windows | Binário distribuído pelo imageio-ffmpeg 0.6.0 | https://github.com/imageio/imageio-ffmpeg e https://ffmpeg.org/download.html |
| Python | 3.12.14 | https://www.python.org/downloads/source/ |
| Tcl / Tk | 8.6.14 | https://www.tcl.tk/software/tcltk/download.html |
| BLT | 2.5.3 | https://packages.ubuntu.com/noble/tk8.6-blt2.5 |
| PyInstaller | 6.22.3, GPL com exceção para os programas gerados | https://github.com/pyinstaller/pyinstaller |

As bibliotecas de sistema incluídas pelo empacotador mantêm seus termos próprios. As licenças de Python, Tcl/Tk, BLT, imageio-ffmpeg, PyInstaller e a GPLv3 do FFmpeg são fornecidas em `licencas/`. O pacote Windows também inclui as licenças disponíveis nos metadados das dependências efetivamente instaladas; suas versões constam em `VERIFICACAO_WINDOWS.json`. O CPK e os áudios originais do jogo não são distribuídos com o editor.
